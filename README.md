Project Title: Simple Calculator
Brief Description: 
        This is a basic web application that performs arithmetic operations such as addition, subtraction, multiplication, and division. It uses HTML for the structure, CSS for the design, and JavaScript to handle calculations and user interactions.

Short Description: 
        This project is a simple calculator for basic arithmetic operations such as addition, subtraction, multiplication, and division. This does not support logical operation so it won't work for AND, OR, NOR, or NOT.
